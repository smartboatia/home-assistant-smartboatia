# Smartboatia for Home Assistant

Home Assistant integration for Smartboatia: live boat data in Home Assistant.

> **Status:** under development. There is no release yet, and this repository is private until the content is final.

## About Smartboatia

[Smartboatia](https://smartboatia.com) builds smart boat monitoring. The Smartboatia Hub collects data from the boat (NMEA 2000, GPS, LTE) and makes it available in the Smartboatia app and cloud. This integration is meant to bring that live boat data into Home Assistant.

Installation via [HACS](https://hacs.xyz) as a custom repository will be described here with the first release.
