# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Send your report by email to **support@smartboatia.com** with the subject "Security: home-assistant-smartboatia". Please include:

- a description of the issue and its potential impact
- the steps needed to reproduce it
- the version of the integration and of Home Assistant you tested with

We will acknowledge your report as soon as we can, keep you informed about the progress and credit you in the fix if you wish. Please give us a reasonable time to fix the issue before you disclose it publicly.

## Scope

This policy covers the code in this repository. For problems with the Smartboatia Hub, app or cloud, please use the same contact address.

## Supported versions

There is no release yet. Once there is one, the latest release is the supported version.
